# OpenTuner M0CKE v1.5.2 — Constellation Layout

## Improved

- **Constellation label:** the mode (for example DVB-S2, or DVB QPSK 1/2 on the Current tab) is now centred underneath the plot.
- **Aligned with the meters:** on the Signal tab the constellation plot now sits level with the tops of the dial meters.
- **Same size on both tabs:** the constellation box is now the same size and position on the Current and Signal tabs, so it no longer jumps when switching between them.

## Included from earlier releases

- v1.5.1: Moving-coil meter needles on the Signal tab.
- v1.5.0: Signal tab for USB MiniTiouner / PicoTuner (dial meters, lock LEDs, constellation).
- v1.4.0: H.266 (VVC) playback via the bundled MPV player.

## Installation

Run `OpenTuner-M0CKE-1.5.2-Setup.exe` on Windows. Existing settings are retained.
